# The package ABI's symbol table, in order: os/api.cpp's kSymbols, one name a line.
#
# A package refers to firmware functions by their INDEX in that table, and a
# package already written to the flash slot keeps those indices across firmware
# updates (pkgslot.cpp checks a CRC over the prefix it was built with). So the
# table only ever grows at the end. Inserting, removing or reordering anything
# moves every index after it: the slot is refused and the package loads into RAM
# instead (Nova D1: from 7 KB of free memory left to the rest of the system).
# tools/check-abi-order.py fails the build when the table and this file differ.
# A new symbol goes at the end of the table AND at the end of this file.
