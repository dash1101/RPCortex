Connect

This browser cannot open serial ports. The page talks to the device through Web Serial, which Chrome and Edge on a desktop computer offer, and only on a secure page (https, or http://localhost). Firefox and Safari do not have it.

The command-line tool does everything this page does: pip install -e tools/rpc, then rpc term.

Plug the board in with a data cable, then choose it. It is listed as RPCortex, or as a Pico.

If the device asks for a login

Used only when the device is at its login prompt. The password is typed into the device and kept nowhere else.

Two ways of talking to the device

The Terminal shows the console as a person sees it. Files, Run, Packages and Device use link mode, a framed channel the device offers to programs, so transfers are checked and every command reports whether it worked. Moving between the two switches the device over; the badge at the top right says which one it is in.

Background messages

Lines the device's services printed while link mode was in use.

None yet.

Firmware update

Resetting to BOOTSEL restarts the board into its bootloader. The connection closes and a drive named RP2350 or RPI-RP2 appears; copy an RPCortex .uf2 onto it and the board restarts with the new firmware. Files on the device are kept.
